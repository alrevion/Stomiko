# Стенд обхода экранов

Приложение требует подписанный `initData`, поэтому в браузере оно не
открывается — а значит экраны никто и не смотрел на телефоне. Отсюда и
дефекты, которые находил владелец, а не проверки: кнопка за нижним краем,
форма, не оживающая при заполнении.

Стенд подделывает только обёртку Telegram. Подпись настоящая, API живой,
код продуктовый — экраны те же, что в телефоне.

## Как запустить

1. `apps/api` → `wrangler dev --port 8787 --local=false`
2. `tsx scripts/qa-screens.mts` — заводит кабинет, врача и пациента,
   печатает подписи.
3. Скопировать `stand.html` и `audit.js` в `apps/miniapp/public/` как
   `_qa.html` и `_qa-audit.js` (в самой папке их держать нельзя: она
   публикуется целиком).
4. Открыть `http://localhost:8787/_qa.html?h=640&d=<подпись>`,
   где `h` — высота видимой части листа Telegram.
5. На каждом экране: `__audit('название')`.
6. После обхода — удалить оба файла из `public/`.

## Что проверяет audit.js

- закреплённое у низа не уходит за видимую границу листа;
- нет горизонтальной прокрутки;
- текст не шире своего контейнера;
- цели касания не меньше 30px;
- последний элемент ленты не прячется за панелью;
- кнопка действия не заезжает на панель навигации.

Граница видимого считается с поправкой: в эмуляторе окна `100dvh` и
`innerHeight` расходятся, на устройстве совпадают. Без поправки проверка
находит «недоступные» кнопки, которых на телефоне нет — я на это уже
попался один раз.
